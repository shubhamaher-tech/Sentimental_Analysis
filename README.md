# Twitter Sentiment Analysis

## Overview
A Natural Language Processing (NLP) project that classifies tweets into three categories:
- Positive
- Negative
- Neutral

The project uses machine learning techniques to analyze tweet text and predict sentiment.

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Matplotlib
- Seaborn

## Dataset
Twitter Airline Sentiment Dataset (Kaggle)

The dataset contains tweets labeled as positive, negative, and neutral sentiments.

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Text Cleaning
4. Feature Extraction using TF-IDF
5. Model Training using Logistic Regression
6. Model Evaluation
7. Sentiment Prediction on New Tweets

## Model Performance
- Algorithm: Logistic Regression
- Accuracy: 79%

## Features
- Cleans and preprocesses tweets
- Converts text into numerical features using TF-IDF
- Classifies tweets into sentiment categories
- Allows users to enter a new tweet and get sentiment prediction
